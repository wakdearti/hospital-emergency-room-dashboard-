# 🏥 Hospital Emergency Room Dashboard

## 📌 Project Overview

The **Hospital Emergency Room Dashboard** is a data analysis and visualization project created using hospital emergency room patient data.

The project analyzes patient admissions, waiting time, patient satisfaction, demographics, and daily emergency room activity. An interactive-style dashboard was designed in **Microsoft Excel** using cleaned data, Pivot Tables, calculations, and charts.

## 🎯 Project Objectives

- Analyze the number of emergency room patients.
- Track daily patient volume and admission trends.
- Analyze average patient waiting time.
- Understand patient admission status.
- Analyze patient satisfaction scores.
- Explore patient demographics such as age, gender, and race.
- Present important hospital KPIs in a simple and easy-to-understand dashboard.

## 📊 Key Dashboard Metrics

The dashboard focuses on:

- **Total / Distinct Patients**
- **Average Patient Wait Time**
- **Patient Satisfaction Score**
- **Admission Status**
- **Daily Emergency Room Patient Trends**
- **Patient Demographics**
- **Monthly / Date-wise Analysis**

## 🔍 Dataset Information

The dataset contains **9,216 patient records** with fields including:

- Patient ID
- Patient Admission Date
- Patient First Initial
- Patient Last Name
- Patient Gender
- Patient Age
- Patient Race
- Department Referral
- Patient Admission Flag
- Patient Satisfaction Score
- Patient Wait Time
- Admission Status

## 📈 Analysis Performed

### 1. Patient Volume Analysis
Analyzed the number of patients visiting the emergency room and their daily trends.

### 2. Waiting Time Analysis
Calculated and visualized the **average patient waiting time** to understand emergency room service efficiency.

### 3. Admission Analysis
Compared patients who were **admitted** and **not admitted**.

### 4. Patient Satisfaction Analysis
Analyzed patient satisfaction scores to understand the patient experience.

### 5. Demographic Analysis
Explored patient information based on:

- Age
- Gender
- Race
- Department Referral

### 6. Dashboard Creation
Combined important KPIs and charts into a single dashboard for quick understanding of hospital emergency room performance.

## 🧹 Data Preparation

The raw CSV data was organized and prepared for analysis. Date/time information, admission status, patient wait time, and satisfaction-related fields were used to create meaningful summaries and visualizations.

Pivot Tables and supporting analysis sheets were created in Excel before presenting the final dashboard.

## 🚀 How to Use

1. Download or clone this repository.
2. Open `Hospital dashboard excel.xlsx` in Microsoft Excel.
3. Open the **DASHBOARD** sheet to view the final dashboard.
4. Use the supporting sheets such as:
   - `pivot report`
   - `daily E.room no.of patient`
   - `Average Wait Time`
   - `Patient Satisfaction Score`
5. The original dataset is available in `Hospital Emergency Room Data.csv`.
